# SPECTER Browser RP v0.3.0

A lightweight persistent open-world RP sandbox for the browser.

Current public runtime includes third-person movement, rigid-body physics, a raycast-suspension car, multiplayer state sync, minimap, day/night, persistent player builds, and autonomous NPCs with memory/goals/resources.

Run:

```bash
npm install
npm start
```

Then open `http://localhost:7860`.

Optional NPC LLM variables are documented in `docs/WORLD_MIND.md`.

The public build does not include or redistribute Rockstar Games assets. The retained GTA-SA compatibility loader is for operator-supplied assets that the operator is authorized to host or read.
